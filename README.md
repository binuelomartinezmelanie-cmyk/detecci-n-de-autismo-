# detecci-n-de-autismo-
pagina web que ayuda a detectar rasgos asociados al CEA en adolescentes de 12 a 18 años. Buscamos ofrecer una herramienta de evaluación accesible, intuitiva y libre de estigmas para un grupo de edad donde el diagnostico suele pasar por desapercibido debido a estrategias de compensación social o "enmascaramiento"
